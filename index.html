Podešavanja

Kontakt broj se štampa u ponudi i internom obračunu i čuva se u cene.json (dugme 💾 Sačuvaj).

GitHub — čuvanje cena

Cene se čuvaju u cene.json na GitHub-u i pri otvaranju se učitavaju na svakom računaru, bez tokena. Token treba samo na računaru sa kog menjaš cene. Polja možeš menjati u svakom trenutku (npr. kada token istekne). Token pravi na GitHub → Settings → Developer settings → Fine-grained tokens, samo za ovaj repozitorijum, sa dozvolom Contents: Read and write. Token se čuva samo u ovom pregledaču.

Posle unosa podataka klikni 💾 Sačuvaj na vrhu stranice: sačuvaće GitHub podešavanja na ovom uređaju i poslati sve izmene (cene, nazive, artikle, pravila, napomenu, kontakt i procente) u cene.json.

Pravila prepoznavanja okova iz CSV krojne liste

Za svaku šifru upiši tekst koji se nalazi u nazivu dela iz SketchUp-a (kolona „Naziv“). Zatim izaberi stavke okova iz cenovnika i koliko komada okova ide na jedan pronađeni deo. Količine i cene se automatski ubacuju u obračun. Pravila se čuvaju na ovom uređaju i ulaze u sačuvani projekat.

Ugrađena pravila prepoznavanja

Ovde menjaš tekst koji aplikacija traži u CSV nazivima i faktore količine za standardni okov. Izmene važe pri sledećem učitavanju CSV fajla.
